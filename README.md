# 로데오공인중개사무소 홈페이지

압구정로데오 로데오공인중개사무소 홈페이지입니다. 글·사진·서비스·사례는 모두 `content/` 폴더의 파일에 들어 있고, **Pages CMS** 화면에서 수정합니다. 코드를 몰라도 됩니다.

## 페이지 주소 (Vercel 배포 기준)

| 페이지 | 주소 |
| --- | --- |
| 메인 | `/` |
| 회사소개 | `/about` |
| 중개 서비스 | `/services` (서비스별 위치는 `/services#lease` 등) |
| 상권·계약 컨설팅 | `/consulting` |
| 매물·중개 사례 | `/projects` (사례는 `/projects#sinsa-clinic`) |
| 상권 인사이트 | `/insights` (글 본문은 `/insights#terms` 등) |
| 문의하기 | `/contact` (분야 선택 상태는 `/contact#clinic` 등) |
| 개인정보처리방침 | `/privacy` |

## 처음 한 번만: 연결하기

1. 이 폴더 전체를 새 GitHub 저장소(예: `apgujeongrodeo/rodeo-homepage`)에 올립니다.
2. Vercel에서 저장소 Import → Framework Preset: **Other** → Deploy. 빌드 설정은 필요 없습니다.
3. https://app.pagescms.org 에 GitHub 계정으로 로그인하고, 이 저장소에 Pages CMS 접근을 허용합니다.
4. Pages CMS에서 저장소를 열면 왼쪽에 아래 메뉴가 보입니다.

## 운영자가 수정하는 곳 (Pages CMS 왼쪽 메뉴)

| 메뉴 | 수정할 수 있는 것 |
| --- | --- |
| 사무소 기본 정보 | 전화번호, 문자 받을 번호, 영업시간, 주소, 등록번호, 로고, 상담 접수 주소 |
| 메인 페이지 | 첫 화면 문구, 소개 글과 사진, 숫자 표기, 신념 문장 |
| 회사소개 | 역사 글, 중개 방식 3가지, 담당자 소개와 사진 |
| 중개 서비스 (프로그램) | 서비스 추가·삭제·순서 변경, 확인 조건, 사진 |
| 상권·계약 컨설팅 | 진행 순서, 비교 항목, 입점 후 도움, 재계약 안내 |
| 매물·중개 사례 (실적) | 사례 추가, 사진·포스터 업로드, 당시 조건, 공개 여부 |
| 상권 인사이트 (글) | 글 추가·수정, 본문 편집기, 사진, 출처 |

저장하면 GitHub에 바로 반영되고, Vercel이 1분 안팎으로 사이트를 다시 배포합니다.

## 지켜 주세요

- **사례(실적):** 자료로 확인된 사례만 올립니다. 계약 성사, 실적 수치, 고객 후기는 확인된 것만 씁니다. 홍보 자료의 조건은 '당시 기준'으로 둡니다.
- **인물 사진:** 김태욱 공인중개사의 기존 홍보 이미지만 씁니다.
- **수치:** 상권 수치를 쓰면 글의 '수치 출처'에 출처와 기준 시점을 꼭 적습니다.
- **영문 키:** 서비스의 '영문 키'는 문의 분야 자동 선택에 쓰이므로 바꾸지 않습니다. 새 서비스를 추가할 때만 영문 소문자로 새로 정합니다.
- **사진 용량:** 사진은 한 장에 1MB 이하(가로 1600px 안팎)를 권장합니다.

## 상담 접수

- 문의 폼(기업명, 담당자, 연락처, 상담 내용, 개인정보 동의)은 Google Apps Script로 구글 시트에 저장되고 알림 메일이 갑니다.
- 연결 방법은 `apps-script/설치방법.md`를 보세요. 연결 전에는 폼이 저장하지 않고, 문자 문안과 전화로 안내합니다.
- 보유 기간: 상담 완료 후 1년. 바꿀 때는 Apps Script, Pages CMS, 개인정보처리방침을 함께 바꿉니다.
- 매물 등록 시스템, 별도 관리자 화면은 후속 단계입니다.

## 파일 구조

```
index.html, about.html, … contact.html   페이지 틀 (수정할 일 거의 없음)
content/*.json                            모든 글과 목록 (Pages CMS가 수정)
media/                                    사진 (Pages CMS 업로드 위치)
assets/site.css, assets/site.js           디자인과 동작
.pages.yml                                Pages CMS 메뉴 설정
vercel.json                               /about 같은 주소 설정
```
