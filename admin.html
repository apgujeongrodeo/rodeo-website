관리자 안내

홈페이지는 두 곳에서
직접 고칩니다

이 페이지는 메뉴에 없고 검색에도 나오지 않습니다. 휴대폰과 PC에 즐겨찾기 해 두세요.

1

글·매물·뉴스·연혁 고치기

Pages CMS에서 고칩니다. 저장하면 1~2분 뒤 홈페이지에 반영됩니다.

Pages CMS 열기
  1. GitHub 계정으로 로그인합니다.
  2. 왼쪽 메뉴에서 고칠 곳을 고릅니다: 단독 매물, NEWS, 상권 인사이트, 회사 연혁·거래 기록, 중개 사례, Q&A 자주 묻는 질문 등.
  3. 새 글은 목록 아래 추가, 사진은 사진 칸에서 올립니다.
  4. 오른쪽 위 Save를 누릅니다.

2

Q&A 답변·상담 접수 확인

구글 시트에서 합니다. 휴대폰은 Google 스프레드시트 앱에서 그대로 됩니다.

접수 시트 열기
  1. [질문] 탭에서 질문 줄의 답변 칸에 답을 적으면 끝입니다. 답변일·답변자·답변완료가 자동으로 들어가고 게시판에 바로 보입니다.
  2. 지우고 싶은 글은 공개 상태를 숨김으로 바꿉니다.
  3. [접수] 탭은 상담 신청입니다. 연락한 뒤 처리 상태를 바꿔 주세요. 완료로 바꾸면 1년 뒤 자동 삭제됩니다.

3

단독 매물 올리는 순서

  1. Pages CMS → 단독 매물 → 추가.
  2. 사진, 가격, 층·면적을 넣습니다.
  3. 광고 필수 항목을 모두 채웁니다: 중개대상물 종류, 총 층수, 사용승인일, 방향, 입주 가능일, 주차 대수, 관리비. 건축물대장(정부24·세움터)에서 확인할 수 있습니다.
  4. 사이트에 공개를 켭니다. 필수 항목이 하나라도 비어 있으면 공개를 켜도 홈페이지에 나오지 않습니다.
  5. 계약이 끝나면 상태를 계약 완료로 바꾸거나 공개를 끕니다. 계약된 매물을 계속 광고하면 안 됩니다.

공개 전 확인: 단독 매물 미리보기 · 연혁 디자인 예시

4

다른 사람에게 권한 주기

  1. 홈페이지 수정: GitHub 저장소 apgujeongrodeo/rodeo-website → Settings → Collaborators 에서 상대 GitHub 계정을 초대합니다.
  2. Q&A·상담: 접수 시트 오른쪽 위 공유에서 상대 구글 계정을 편집자로 추가합니다.
