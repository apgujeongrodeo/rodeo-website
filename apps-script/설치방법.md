# 상담 접수 연결 방법 (처음 한 번, 약 5분)

홈페이지의 상담 신청을 구글 시트에 저장하고, 알림 메일을 받도록 연결합니다.

## 0. 먼저 확인할 것

- 접수 시트를 만들 Google 계정을 정합니다. **사무소 계정(rodeo.apgujeon@gmail.com) 사용을 권장합니다.**
- 그 계정의 Google 저장공간에 여유가 있어야 합니다. 저장공간이 가득 차면 시트를 만들 수 없고, Gmail로 메일을 받는 것도 막힐 수 있습니다. (https://one.google.com/storage 에서 확인)
- 그 계정에 2단계 인증을 켜 둡니다.

## 1. 접수 시트 만들기

1. 위 계정으로 https://sheets.new 를 엽니다.
2. 파일 이름을 `로데오 홈페이지 상담 접수`로 바꿉니다.
3. 이 시트는 **다른 사람과 공유하지 않습니다.** (필요한 담당자만 개별 초대)

## 2. 스크립트 붙여넣기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본으로 있는 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣습니다.
3. 맨 위 `NOTIFY_EMAILS`의 알림 받을 메일 주소가 맞는지 확인하고 저장(디스크 아이콘)합니다.
4. 위쪽 함수 선택 칸에서 `setup`을 고르고 **실행**을 누릅니다.
5. 권한 확인 창이 뜨면 계정을 선택하고 허용합니다. ("확인되지 않은 앱" 경고가 나오면 고급 → 이동을 누릅니다. 내 계정에서 내가 만든 스크립트라 나오는 안내입니다.)
6. 시트에 `접수` 탭과 머리글이 생겼는지 확인합니다.

## 3. 웹 앱으로 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(톱니바퀴)에서 **웹 앱**을 고릅니다.
3. 다음과 같이 설정합니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
   - 이 주소로는 접수만 할 수 있고, 시트 내용을 볼 수는 없습니다.

## 4. 홈페이지에 연결

1. Pages CMS → **사무소 기본 정보** → `상담 접수 주소` 칸에 복사한 URL을 붙여넣고 저장합니다.
2. 1~2분 뒤 홈페이지 `/contact`에서 테스트로 한 건 신청해 봅니다.
3. 시트에 한 줄이 생기고 알림 메일이 오면 연결 완료입니다. 테스트 줄은 지워 주세요.

## 운영 방법

- 연락을 마치면 `처리 상태`를 `연락 완료`, 상담이 끝나면 `완료`로 바꿉니다. `완료`로 바꾸면 완료일이 자동으로 찍힙니다.
- 완료일로부터 1년이 지난 줄은 매일 새벽 자동으로 삭제됩니다. (개인정보처리방침의 보유 기간과 같습니다)
- 알림 메일은 처리 후 지워 주세요.
- 보유 기간이나 동의 문구를 바꾸면 `Code.gs`의 `RETENTION_DAYS`, `CONSENT_VERSION`과 Pages CMS의 같은 항목, 개인정보처리방침을 함께 바꿔야 합니다.
- 스크립트를 수정한 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 주소는 그대로입니다.
